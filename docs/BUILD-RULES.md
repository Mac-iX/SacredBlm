# Sacred Bloom Wellness — Build Rules

## Homepage direction

Raechel's hand-drawn landing-page sketch controls the visible hierarchy more than generic marketing frameworks do.

1. Large arched/mosaic visual area on the left.
2. Sacred Bloom logo/mark on the right.
3. The hero mosaic should feature singing bowls, crystals, and aromatherapy in a tactile editorial composition.
4. Transition into the offering cards with a meaningful line from Raechel's own writing.
5. Offering cards link to full offering/product pages.
6. Calendar and event posters follow the offering area.
7. About, testimonials, and contact come later in the journey.

## Visual palette

Use the supplied coastal references as atmosphere and palette:
- blush and pale pink cloud tones
- aqua / seafoam / turquoise water
- pale blue-lilac sky
- warm cream
- restrained gold/bronze from the brand mark

Do not ship watermarked reference photography.

## Anti-slop rules

Do not add:
- tiny uppercase eyebrow copy above every section
- numbered labels such as 01 / 02 / 03
- fake dashboard indicators
- generic mystical icons
- template filler such as "a sacred space for transformation"
- synthetic testimonials
- stock "woman in white doing yoga" clichés
- excessive gradients, particles, parallax, or animated spiritual effects
- content that explains the design instead of serving the visitor

Headings should simply say what the section is.

## Interaction

Desktop offering cards may reveal short supporting copy on hover/focus.
Mobile must show enough information without hover.

## Missing-media protocol

If an image is not final, preserve a structured frame with:
- asset ID
- intended subject
- aspect ratio
- alt-text guidance
- optional caption purpose

This lets a future image be dropped into the correct location without guessing.

## Production rule

Build on a dedicated branch. Do not modify main until the homepage and core offering flow are reviewed.
